Курсовая работа по предмету "БД и СУБД" по теме Проектирование и реализация информационной системы "Авторемонтная мастерская"
В качестве БД использовалась Postgresql
Для написания клиентского приложения использовался react+vite, а также html+css
Для написания серверной части использовался NodeJS, а именно библиотека ExpressJS
